Software Testing

Software Testing is the process of checking whether a software application meets the specified requirements and works correctly.

Types of Software Testing

  • Manual Testing
  • Automation Testing
  • Performance Testing
  • Django

Manual Testing

Manual Testing is performed by testers without using any automation tools.

Automation Testing

Automation Testing uses tools like Selenium to execute test cases automatically.

Manual Testing is performed by testers without using any automation tools.
